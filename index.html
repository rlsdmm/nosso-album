Ativar edição ✏️

Pra salvar pelo site, o álbum precisa de uma chave do GitHub que só mexe nele. Ela fica guardada criptografada com a nossa senha.

  1. Abra github.com/settings/personal-access-tokens/new
  2. Nome: album. Validade: a maior que tiver.
  3. Repository access: Only select repositories → nosso-album
  4. Permissions → Repository → Contents: Read and write
  5. Clique em Generate token e cole aqui embaixo

Senha de visitante 👀

Só na primeira vez: pra visitante não conseguir editar, a chave do GitHub vai passar a ser protegida só pela senha principal. Como a chave atual ficou guardada nos registros antigos do álbum, ela precisa ser trocada:

  1. Abra github.com/settings/personal-access-tokens
  2. Clique na chave album → Regenerate token
  3. Copie a chave nova e cole aqui embaixo
